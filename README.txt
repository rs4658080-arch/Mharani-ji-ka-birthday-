MY MAHARANI - BIRTHDAY WEBSITE

1. Extract this ZIP.
2. Upload the contents (index.html and the photos folder) to a new GitHub repository.
3. In GitHub, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. Once GitHub gives you the live website URL, use that URL to create a QR code.
6. Share the QR code with Madam Ji.

The page is mobile-friendly. Tap any photo to view it larger.
